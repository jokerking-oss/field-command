# 兵种立绘来源与许可

生产面板（部署新部队）里 8 张兵种写实图，全部取自 **Sketchfab** 公开搜索结果，
按「同类正确条目中点赞数（likeCount）最高」挑选 —— 即社区点赞排行验证过的大众审美，
并排除低多边形（low poly）、无材质（no material）与搜偏条目。

- 每张图的模型页地址、作者、精确许可见同目录 `CREDITS.json`。
- 侦察车一栏主动避开了点赞更高但带「Z」字军事涂装的 GAZ TIGR（151 赞）。
- 轻型坦克点赞最高的是 Sci-Fi Tank（176，非写实）与 Panzer II（169，渲染过暗），
  最终选用 War Thunder 官方风格的 M24 Chaffee 渲染图（画质最好、干净摄影棚背景）。
- 后处理：内容居中裁方 + 统一战地调（降饱和/压暗/冷灰罩/暗角），192×192 WebP。
- **若将来商用**：CC-BY 要求署名，保留本文件与 CREDITS.json 即可满足；
  替换素材时同样记录来源。
